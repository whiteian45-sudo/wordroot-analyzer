词根词缀分析器 —— 使用说明
=================================

【这是什么】
一个本地小工具：输入英文单词，拆出它的前缀 / 词根 / 后缀，解释每一部分
的意思，还能看词源演变链、同根词。另外做了词频分级浏览、例句搜索和
间隔重复复习。例如：
  transport → trans-(横穿) + port-(搬运)
  bicycle   → bi-(两个) + cycle-(轮子)，cycle ← 希腊语 kyklos

所有数据和处理都在本机，不联网、不上传任何内容。

【怎么用】
双击 start.bat，会自动：
  1. 启动本地服务（Python）
  2. 另开一个「Kokoro TTS」窗口（高音质发音服务，可选）
  3. 打开浏览器进入工具页
输入单词按回车即可。关掉主服务那个窗口即退出，TTS 窗口可单独关。

注意：不要直接双击 index.html —— 浏览器会拦住页面读取数据，必须走
start.bat（或手动 python server.py）。

【查词逻辑】
按顺序查，命中一层就停：
  1. enhanced.json  约 1.4 万考试常用词（最全：音标/释义/词根分解/词源/例句）
  2. oxford.json    牛津高阶9（可选文件）
  3. ecdict.json    约 76 万词的全量英汉词典（兜底）
  4. 内置规则引擎   词根词缀表（三千余条），最后兜底

【主要功能】（界面上有五个页签）
  查询   单词拆解、词源演变链、同根词、拼写纠错、段落模式、短语卡
  词根   浏览内置词素表，看每个词根 / 前缀 / 后缀带哪些词
  词频   按 BNC-COCA 词频分级（1k–9k 千词族）浏览，可随机抽 20 个词族自测
  例句   在库里的全部例句中搜索
  收藏   收藏夹、查词记录、间隔重复复习（闪卡：先看词，再揭晓自评）

  快捷键：/ 聚焦搜索框，空格朗读当前词（Shift+空格 慢速），
          [ ] 上一个 / 下一个词，Alt+← 退回上一个词；
          复习中 空格 / Enter 揭晓答案，1 忘了，2 记住了。

【文件清单 - 必须】（少一个都启动不了）
  start.bat        双击启动

【发音】
不装任何东西也能用浏览器自带的语音点 🔊 朗读。
想要更自然的音质，可以装 Kokoro（可选）：
  pip install kokoro soundfile torch --index-url https://download.pytorch.org/whl/cpu
  然后双击 tts_start.bat（独立黑窗口常驻）
首次运行会自动下载模型（约 300MB，需要联网）。没装会自动退回浏览器语音。

【深度讲解 / AI 助记 / 整段翻译】（可选）
这三个按钮走本地大模型（Ollama），需要自己装：
  1. 到 ollama.com 下载安装 Ollama，装完保持后台运行
  2. 命令行执行：ollama pull qwen3:4b-instruct-2507-q4_K_M（约 2.5GB）
没装的话，这三个按钮点了会提示连接失败，其它功能完全不受影响。

【开发文件】（普通查词用不到）
  test_*.js、tune_scoring.js、test_health.js、guard_words.json、回归.bat、audit_report.md
  改拆解引擎/词素表后跑一遍回归用的：双击 回归.bat 即可（需要装 Node.js）。

【常见问题】
  双击后出现两个黑窗口 → 正常。一个是词库主服务，另一个是发音服务（Kokoro），
      后者可以单独关掉，关掉只是少了高音质发音。
  双击后页面打不开 → 多半是 Python 没装好。确认装了 Python 3，
      或手动运行 python server.py 看报什么错。
  提示"端口被占用" → 服务已经在跑了，直接用打开的那个浏览器页面即可。
  改了 server.py 不生效 → 前端改动刷新页面就行，后端改动要关掉黑窗口重启。
  查词记录 / 收藏存哪 → 项目目录下的 history.json 和 favs.json（自动生成）。
  深度讲解 / 发音没反应 → 见上面【深度讲解】【发音】两节。
